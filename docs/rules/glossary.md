# Glossary

Last updated: 2026-09-07

## IP

A reusable creative property: story world, characters, tone, visual style, and continuity rules.

## IP Asset

A reusable production asset inside an IP, such as a character reference, wardrobe, location, prop, voice, or visual style pack.

## Character

A person or persona inside an IP. A character should have stable appearance, wardrobe, behavior, and reference assets.

## Character Version

An immutable production snapshot of a Character's appearance, wardrobe, references, voice metadata, and prompt constraints.

## Reference Pack

An ordered, model-ready collection of assets used to anchor a Character, location, prop, or visual style during a generation request.

## Script Version

A versioned source narrative for an Episode. It includes story beats, scenes, dialogue, source language, and authoring history.

## Episode

One short-drama production unit. It contains script, scenes, shots, generated candidates, selected takes, and final exports.

## Storyboard

The editable visual production plan that groups an Episode into Scenes and Shots before generation.

## Scene

A story block in a shared location/time/context. A scene contains one or more shots.

## Shot

One independently generated video unit, usually 4 to 12 seconds for current AI video models.

## Candidate

One generated option for a shot.

## Selected Take

The candidate chosen for the final episode timeline.

## Episode Version

An ordered set of selected takes plus edit, audio, caption, and export configuration. It is the source for a final release.

## Subtitle Track

A timed, language-tagged subtitle record with text, speaker, and styling or export settings.

## Localized Episode Version

A child Episode Version that preserves its source version and adds explicit subtitle and audio language choices.

## UI Locale

The language used by Studio controls and system copy, currently planned for zh and en routes.

## Content Locale

The language of an Episode's script, dialogue, subtitle track, dubbing track, or export. It is independent from the UI locale.

## Assembly

The process of joining selected takes and applying trim, BGM, captions, watermark, and export format.

## Continuity

The practice of keeping characters, locations, wardrobe, props, and visual style stable across shots and episodes.
