# Xcity Studio 产品价值与订阅商业化规划

> 本文基于 Xct Studio 截至 2026-09-16 的仓库实现与提交历史整理。文中的能力分为“当前已具备”“部分具备”和“规划新增”，不将产品规划描述成线上现状。以下全部价格均为美元（USD）建议试点价，不是当前线上收费承诺；正式上线前仍需用真实供应商结算、支付费率、存储与客户测试校准。

## 一、产品定位与价值

Xcity Studio 正在从单条 AI 视频生成工具演进为短剧生产工作台。产品同时服务两种需求：

- **Short Video**：面向未订阅用户，完成单条文生视频、图生视频、参考素材生成、预览、下载与分享。
- **Short Drama**：面向订阅用户，将剧本、角色资产、场景、分镜、视频生成、审核、字幕、成片、分发和创收组织成项目化生产流程。

Studio 的核心价值不是简单聚合模型，而是把模型能力组织成一条可控制、可恢复、可审核、可复用的内容生产链：

> 创意或剧本 → 角色与场景 → 分镜审阅 → 资产绑定 → 镜头生成 → 结果选择 → 成片组装 → 字幕与本地化 → 分发与创收

这条链路主要解决四个问题：

1. **降低随机性**：通过多参考素材、Asset ID、人物审核、分镜配置和连续性约束提高角色与视觉一致性。
2. **降低试错成本**：以草稿、成片、费用预估、任务恢复和单镜头重试替代一次性高成本生成。
3. **沉淀生产资产**：保存角色、场景、素材、提示词、参数、历史结果和项目记录，使一次创作可以服务后续镜头与剧集。
4. **形成商业闭环**：让内容从“生成一个文件”继续走向版本管理、字幕、本地化、分发、数据回收和收入结算。

## 二、当前能力边界

### 当前已具备

- Seedance 文生视频、图生视频及多模型选择；
- 多参考图、参考视频、首尾帧、续片、运镜和提示词辅助；
- 生成历史、费用估算、失败恢复与 R2 媒体归档；
- 图片、视频、音频等资产管理及统一视频播放器；
- 真人素材认证、供应商审核、Asset ID 状态及准入控制；
- TXT、Markdown、DOC、DOCX、PDF 剧本导入与 AI 拆解；
- 短剧项目创建、配置、角色/场景/分镜草稿审阅、资产绑定和 Preflight；
- PostgreSQL 通用业务记录、revision、事务及队列 claim 基础；
- 视频组装、剪切、BGM、字幕、SRT、部分双语字幕和 FCP7 XML；
- 公开分享、一键复刻及审核后进入作品广场。

### 部分具备

- 短剧 P0 主流程已有，但完整强类型 Project、Episode、Scene、Shot 模型尚未交付；
- 剧本可以导入和拆镜，但还不是完整的版本化编剧系统；
- 分镜可以审阅和生成，但 Candidate 对比、Selected Take、锁定及 Episode Version 尚未形成完整闭环；
- 字幕和双语输出已有，完整翻译审阅、配音版本和 Localized Episode Version 尚未完成；
- 作品分享和平台规格导出已有，外部平台直发、数据回收和收益结算尚未实现；
- 服务端已有持久化底座，但部分供应商任务提交和轮询仍由浏览器驱动。

### 规划新增

- 月付、年付订阅及功能权限系统；
- Studio Token 钱包、账本、预授权、结算、退回和加油包；
- 未订阅用户仅能使用 Short Video 的产品隔离；
- Story Bible、人物关系、时间线、伏笔及长期故事记忆；
- Plan → Draft → Audit → Revise 专业编剧 Agent；
- 完整镜头候选、选片、版本化成片及连续性检查；
- 分发中心、渠道数据、付费内容、收入账本和创作者分账；
- 团队席位、组织权限、批量生产 API 和项目利润分析。

## 三、美元订阅与用量定价建议

订阅和 Token 解决不同问题：

- **订阅**购买短剧工作流、编剧能力、云端项目、资产空间、分发权限和服务等级；
- **Studio Token**是美元计价的预付用量单位，用于支付语言模型、图片、视频、TTS、转写和翻译等计算资源；它不是供应商的原生推理 token。

未订阅用户即使购买 Token，也只能在 Short Video 模式中使用，不能创建或编辑短剧项目，不能调用短剧剧本、分镜、分发和创收能力。

### 市场参照与定价立场

截至 2026-09-16，[AtlasCloud 视频模型定价页](https://www.atlascloud.ai/zh/pricing/models?type=video)及其[Seedance 2.0 产品页](https://www.atlascloud.ai/zh/seedance-2)展示：Seedance 2.0 Fast 低至约 **$0.027/秒**、2.0 低至约 **$0.09/秒**；[Seedance 2.5 产品页](https://www.atlascloud.ai/zh/seedance-2-5)展示低至约 **$0.134/秒**。这些是 AtlasCloud 的公开 API 起价，不保证相同分辨率、输入模式、音频和参考素材组合，更不是 Xcity 当前 BytePlus/TokenHub 的采购成本。AtlasCloud 的 Mini 型号也不是 Studio 当前已接入型号，不能混为同一 SKU。

Studio 不应与纯 API 按秒价格战。售价包含剧本与分镜工作流、人物与资产一致性、审核、项目版本、成片、云端协作及计划中的分发创收能力。订阅费购买这些产品能力；模型用量另按美元零售价扣除。高耗能模型不能因订阅而“无限生成”。

| --- | ---: | ---: | ---: | --- |
| Clip Free | $0 | $0 | 注册试用最多 200（$2），限一次并做防滥用 | 短视频体验用户 |

| Drama Pro | $499/月 | $4,990/年 | 15,000（$150） | 职业创作者、小团队 |
| Studio Business | $1,499/月 | $14,990/年 | 45,000（$450） | MCN、工作室、内容公司 |
| Enterprise | 建议 $3,000/月起 | 合同报价 | 按保底量、并发与 SLA 单独报价 | 大型机构和渠道方 |

### 模型用量：建议零售价，而不是成本透传

建议定义 **100 Studio Token = $1 用户可消费零售额度**。界面同时展示原生模型用量、预计扣除的 Studio Token 和 USD 等值；不要把“供应商原生 token”“Studio Token”和“美元成本”混写。以下为 16:9、720p、无参考视频的**试点零售价下限**，按实际配置在提交前给出确定报价：

| 当前接入模型 | 建议零售价下限 | 10 秒示例 | 折合 Studio Token |
| --- | ---: | ---: | ---: |
| Seedance 1.5 Pro，带音频 | $0.12/秒 | $1.20 | 120 |
| Seedance 2.0 Fast | $0.25/秒 | $2.50 | 250 |
| Seedance 2.0 | $0.32/秒 | $3.20 | 320 |
| Seedance 2.5 | $0.55/秒 | $5.50 | 550 |

这组建议价刻意高于公开 API 起价，销售的是 Studio 工作流，不是声称这些就是 BytePlus 结算价。当前仓库的 `src/shared/config/seedance.ts` 与生成费用计算只提供**现行网关映射下的估算**，其中 2.5 的映射已注明含 Xcity 加价；不能据此推导最终毛利。上线前按真实账单逐 SKU、分辨率、音频、参考视频、区域核对，正式报价取 `max(上表对应配置的零售下限，实际全量可变成本 ÷ 0.45)`；后者对应**至少约 55% 的可变毛利目标**，不是已经实现的财务结果。全量可变成本包括供应商推理、媒体转码/存储/流量和支付手续费，不包括固定研发及销售费用。若真实成本或竞品价格变化，应调整价目表并对用户生效前明确告知，不追溯扣费。

参考视频、1080p 等高配项按实际成本另报价，不能沿用 720p 表格。非视频模型也必须有经审核的零售费率；不能直接将供应商结算美元乘以 100 作为扣费，否则没有覆盖产品成本和毛利。提交任务前预估并预留零售额度，成功后依预先展示的计费规则结算；失败且无供应商费用时全部释放，有供应商费用的异常场景须有清晰申诉和人工处理，不向用户展示内部网关结算明细。

建议充值包：2,500 Token / **$25**、10,000 Token / **$100**、50,000 Token / **$500**，先不打折；Enterprise 才按保底消费与实际毛利谈阶梯折扣。充值只增加计算余额，不解锁更高套餐功能。面向用户以 USD 金额为主、Studio Token 为辅助；税费、退款、赠送额度消耗顺序和跨境支付规则在结账前明确展示。

### 财务校准与上线闸门

- 先用至少 30 天真实任务按模型、分辨率、时长、输入模式统计成功率、实际供应商费用、重试及退款，覆盖 P50/P95，而不是用官网“低至”价格做预算。
- 试点关注每档订阅的收入、赠送额度实际消耗、可变毛利、付费转化和流失。按赠送额度**全部用完**、且用量零售价满足 55% 可变毛利目标估算，Creator / Pro / Business 的模型及相关可变成本上界约为 **$13.50 / $67.50 / $202.50 每月**；这只是预算压力测试，不是实测利润，也未计入订阅服务的固定成本。
- 若供应商成本无法核实、按配置报价不能正确预留/结算，或 P95 高用量用户使边际贡献转负，先限制对应 SKU 或并发，暂不对外承诺此价格。正式发布前由财务、产品和法务共同确认价目表与条款。

## 四、专业编剧能力规划

Studio 可参考 [screenwriting-skills](https://github.com/jtydhr88/screenwriting-skills) 的能力分类，将编剧方法产品化为结构化任务，而不是只增加一个聊天窗口：

- 前提、主题、Logline、类型与故事结构；
- 人物动机、成长弧、关系网、对手与冲突；
- 场景目标、价值转折、节奏、动作与对白；
- 系列引擎、Story Bible、分集大纲、A/B/C 线和结尾悬念；
- 中文剧本格式、小说/IP 改编、竖屏短剧节奏和制作限制检查。

同时参考 [InkOS](https://github.com/Narcooo/inkos) 的产品思路，为项目建立长期可编辑状态：作者意图、当前重点、世界观、人物关系、时间线、待回收伏笔、分集摘要、连续性状态和风格档案。推荐的 Agent 流程为：

> 策划 → 故事架构 → 编剧 → 审稿 → 修订 → 人工确认 → 分镜 → 导演与制片检查

AI 可以生成草稿和建议，但发布正式剧本、替换已确认资产、发起付费批量生成、扩大预算、替换锁定镜头及对外发布必须由用户确认。

许可证边界必须保留：`screenwriting-skills` 的技能代码采用 MIT，但其引用的出版物与剧本不在 MIT 授权内；InkOS 核心采用 AGPL-3.0。若 Xcity Studio 保持专有，应以产品和架构参考、独立实现为主，不直接复制 AGPL 核心代码或受版权保护的原始内容。

## 五、分发与创收规划

分发建议分三步建设：

1. **发布包**：生成视频、封面、标题、简介、标签、字幕、版权和授权资料；
2. **渠道连接**：对具备开放接口的平台实现授权直发，其余平台继续提供标准发布包；
3. **数据与收入**：回收播放、完播、转化、收入和单集成本，形成项目利润分析。

创收形态可以包括付费短剧、单集/全集购买、会员观看、广告分成、模板销售、剧本模板、角色/IP资产授权和商业定制。建议 Drama Pro 按可分配净收入收取 15% 平台服务费，Studio Business 收取 8%，Enterprise 通过合同约定。可分配净收入应在扣除支付通道费、税费、退款和渠道分成后计算；制作 Token 属于创作成本，不再从收入中重复扣除。

## 六、建议实施顺序

1. **商业化底座**：套餐、订阅状态、功能权限、Token 钱包、不可变账本和短视频/短剧入口隔离；
2. **编剧系统**：Story Bible、版本化剧本、长期记忆、编剧技能、审稿和修订；
3. **生产闭环**：正式 Scene/Shot、Candidate、Selected Take、Episode Version、连续性和服务端任务恢复；
4. **分发创收**：发布包、渠道连接、内容付费、收入账本、分账和数据分析。

Xcity Studio 的长期竞争力不是绑定某一个模型，而是持续沉淀专业编剧能力、IP 与角色资产、生产记录、审核与授权、透明成本以及从创作到收入的闭环。最终定位是：**面向个人创作者和内容团队的 AI 短剧生产与商业化基础设施。**
