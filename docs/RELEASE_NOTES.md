# Xcity Video Studio 2.1 发布声明

_2026-08-12 · studio.xcity.ai_

这是 Studio 迄今最大的一次升级：从"单条视频生成器"进化为**完整的 AI 视频创作工作台**。
本次发布覆盖 Seedance 2.5 接入、多模态参考创作、分镜工作流、成片剪辑导出与作品社区，
共 18 个 PR、四个大版本波次。

---

## 🎬 Seedance 2.5 正式可用

- **30 秒单镜头 · 4K 输出**：Seedance 2.5（`dreamina-seedance-2-5-260628`）全面接入，
  支持最长 30 秒连续镜头与 4K 分辨率；
- **多镜头叙事**：在提示词中直接编写编号镜头序列与 `{台词/BGM}` 音频提示，一次生成多镜头短片。

## 🖼️ 多模态参考 — 让生成不再随机

- **多参考图（1–9 张）**：锁定主体、场景与风格，提示词用 `[Image 1]`、`[Image 2]` 精确引用；
- **参考视频（最多 2 个）**：模仿运镜/风格、定点编辑、镜头转场（`[Video 1]` 引用）；
- **参考音频**：BGM 与音色锁定（`[Audio 1]` 引用），或直接用内置 **TTS 生成配音**；
- **首尾帧控制**：指定第一帧与最后一帧，精确控制转场与落点；
- **续片 Extend**：任何完成的视频一键"从最后一帧继续"，突破单次时长上限；
- 参考媒体全部自动内联传输，杜绝"图片下载失败"类错误。

## 🎯 创作工作流

- **分镜编写器（Shots）**：逐镜头编排描述/运镜/音频提示，一键编译进提示词；
- **一键分镜**：粘贴剧本，AI 自动拆解为结构化镜头序列；
- **16 组运镜预设**：crash zoom、dolly zoom、snorricam、speed ramp……点击即用；
- **命名角色（Characters）**：把资产图片升格为命名角色，跨项目一键挂载，保持主体一致性；
- **AI 提示词优化**与灵感模板持续可用。

## 💰 草稿模式与诚实计费

- **草稿 → 成片阶梯**：新任务默认 480p 草稿档快速试错（低至约 1/5 价格），满意后一键
  **Finalize** 以同一 seed 在目标画质复现；
- **精确报价**：提交前显示精确美元成本（非模糊积分）；
- **计费透明**：失败任务如实显示已产生的费用，总账不再有隐藏项。

## ☁️ 云端工作台

- **历史跨设备同步**：创作历史与设置云端保存，换浏览器、换电脑无缝继续（本地离线可用）；
- **资产库 Assets**：上传的参考图/音频/视频与生成的视频统一管理——命名、筛选、复用、删除。

## ✂️ 成片与导出

- **组装编辑器**：多片段按序拼接，支持每片段入/出点剪辑、背景音乐混音（音量可调），
  全程浏览器本地处理，不上传不排队；
- **自动字幕**：成片一键转写生成字幕（烧录或 .srt 文件）；
- **平台导出预设**：9:16（抖音/Reels/Shorts）、1:1、16:9 一键重构图导出；
- **专业交接**：导出 FCP7 XML 时间线，直接导入 Premiere / DaVinci Resolve 继续精剪。

## 🌐 分享与作品广场

- **公开分享页**：一键生成作品页——视频、完整提示词与参数公开可复制，
  访客点击 **Recreate** 即可在 Studio 中以相同设置再创作；
- **作品广场（Community）**：把作品提交到广场，经审核后公开展示；广场作品均可一键复刻。
  广场只做创作展示与复刻，无信息流干扰。

## 🔧 稳定性修复（本周期内）

- 修复 Seedance 2.5 被误报"API Key 失效"的问题（模型权限错误分类）；
- 生成进度实时平滑显示；完成后预览不再卡"loading"（CDN 链接延迟附着的退避重试）；
- 图生视频修复：首帧模式自动省略 ratio（跟随图片比例）；
- 参考媒体改为 Base64 内联 + 自有域名 media.xcity.ai，彻底解决供应商抓取失败；
- 粘贴参考图 URL 即时生效；死链提交前拦截并明确提示。
